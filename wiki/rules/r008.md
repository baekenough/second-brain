# R008: Tool Usage Identification Rules

**Priority**: MUST | Every tool call must be prefixed with agent and model identification before the tool call block.

## Overview

R008 ensures tool usage is transparent — users can see which agent is making which tool calls. This is especially important for parallel agent spawns where multiple tool calls happen simultaneously. Identification must appear BEFORE the tool calls.

## Format

```
[agent-name][model] → Tool: <tool-name>
[agent-name][model] → Target: <file/path/url>
```

For parallel calls: list ALL identifications BEFORE the tool calls.

## Tool Category Verbs

| Category | Tools | Verb |
|----------|-------|------|
| File Read | Read, Glob, Grep | Reading / Searching |
| File Write | Write, Edit | Writing / Editing |
| Network | WebFetch | Fetching |
| Execution | Bash, Agent | Running / Spawning |

## Parallel Spawn Prefix Rule

When spawning 2+ agents, each description must include `[N]` prefix:

```
[secretary][opus] → Spawning:
  [1] lang-golang-expert:sonnet → Go code review
  [2] lang-python-expert:sonnet → Python code review
```

Single agent spawns do NOT use the `[N]` prefix.

## Agent Tool Format

```
subagent_type:model → description
```

`subagent_type` MUST match actual Agent tool parameter — custom names not allowed.

## Context Drift Mitigation (Multi-Turn Sessions)

The same drift risk that affects [[r007]] applies to R008's per-tool-call prefix:

| Window | Why |
|--------|-----|
| Turn opens with a subagent completion notification | Not user input — weak trigger to recall the rule |
| 5+ chained tool calls in a diagnostic sequence | No per-call re-check, only early-context rule |
| Aggregating results from 3+ parallel agents | `[agent][model] → Tool:` prefix skipped while synthesizing |
| Turn resumes immediately after context compaction | Resume instruction to skip meta-preamble over-applied to the prefix |

**Self-check**: confirm the `[agent-name][model] →` prefix immediately before every tool call in these windows — notification-opened and auto-resumed turns are governed by R008 exactly like user-input turns.

**Compaction-resume distinction**: resume instructions forbid mentioning the summary, not the tool-call prefix. The prefix is a structural part of the tool call, not preamble, so no resume instruction waives it.

**Recurrence**: same 2026-08-18 double-omission session as [[r007]] (both user-flagged via `@CLAUDE.md 재주입`). A third omission on 2026-08-26 dropped both the R007 header and the R008 prefix together on an automatic post-compaction resume turn, not a user-input turn.
