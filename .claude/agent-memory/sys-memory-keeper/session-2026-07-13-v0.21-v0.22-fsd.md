## 세션 개요

FSD(구조화 개발 사이클) 자율주행 2회전. 세션 시작 시 upstream force-push(보안 redaction 재작성)로 로컬 main을 origin에 리셋(backup: `backup/pre-force-sync-20260713`) — 로컬 stale memory 편집분은 사용자 결정으로 폐기.

## Run 1 → v0.21.2 (milestone #23)

통화데이터 보안 수정 3건:

- **#163**: transcript Content+Title 구조적 PII redaction (`smsmap.RedactPII` 적용)
- **#164**: sidecar number_hash, 파일명 해싱, 익명 통화 Title fallback `"상대 {hash8}"` (API ingest + `smsmap.MapCall` 양쪽), 로그 sanitization.
  - deep-verify adversarial review가 릴리즈 전 **CRITICAL bypass 경로** 3개(파일명/Title/로그) 발견 → iteration 내 수정
- **#165**: diarization hard-local guard + HTTP redirect 거부

CI에서 신규 CVE 2건 발견 → Go 1.26.5 + pgx v5.9.2 bump (commit `45cba92`). 릴리즈 게이트: CI all-jobs-green 확인 후 태깅.
