NOTE (Step 6 resolution): No schema_migrations table exists by design.
internal/store/postgres.go RunMigrations() re-applies all *.sql files under
migrations/ on every server boot (idempotent, advisory-lock guarded), with
no version ledger table. Source-of-truth "applied version" = highest
migration file in migrations/ dir at deploy time = 026_search_weights_history.sql
(latest file present in repo as of 2026-08-19). Baseline fingerprint is
therefore: index inventory (Step 5, 64 rows) + table list (16 tables) +
migrations/ directory listing, not a DB-side version number.
